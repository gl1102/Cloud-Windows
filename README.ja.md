# ☁️ Cloud-Windows — 無料のクラウド Windows デスクトップ

GitHub Actions の無料 Windows 仮想マシンを、ブラウザから使えるクラウドデスクトップに。Web ページを開けば Windows PC が使えて、使い終わったら閉じるだけ。完全無料です。

## ✨ 機能

- 🖥️ フル機能の Windows デスクトップをブラウザで直接操作（noVNC Web クライアント）
- 📐 **自動解像度**：ページを開くとブラウザのウィンドウサイズに合わせてデスクトップ解像度が自動調整。スマホも PC もそれぞれ最適化され、ウィンドウサイズを変えると追従します
- 🌐 Cloudflare トンネル経由でアクセス。グローバル IP 不要、ポート開放不要
- ⌨️ 搜狗入力（Sogou Pinyin）内蔵。中国語入力がそのまま使えます（`Win + Space` で中/英切り替え）
- 🖱️ スマホ・タブレット・PC から接続可能
- ⏱️ 1 回の実行は最大約 6 時間。いつでもキャンセルできます
- 📦 **RustDesk 版**：RustDesk 入りのワークフローもあります。最新版の RustDesk インストーラーを Desktop に自動ダウンロードします（リモート操作が必要な場合は自分でインストールするか、ポータブル版を使ってください）

## 🚀 使い方（fork したらすぐ使える）

### ステップ 1：このプロジェクトを Fork

このページ右上の **Fork** ボタンをクリックして、プロジェクトを自分の GitHub アカウントにコピーします（fork するのは `main` ブランチです。テスト用の `test` ブランチは選ばないでください）。Fork が終わると `あなたのユーザー名/Cloud-Windows` というリポジトリに入ります。

> 💡 なぜ fork が必要？ GitHub Actions は自分のアカウントのリポジトリでしか実行できません。fork することで実行する権限が得られます。

### ステップ 2：クラウドデスクトップを起動

1. fork したリポジトリのページを開き、上部の **Actions** タブをクリック
2. 左側でワークフローを選択します（どちらか一方）：
   - **Windows Cloud Desktop**：標準版クラウドデスクトップ
  - **Windows Cloud Desktop + RustDesk**：標準版に加え、最新版の RustDesk インストーラー（`rustdesk-x.x.x-x86_64.exe`）を Desktop に自動ダウンロード（バージョンはハードコードせず、毎回公式の最新リリースを取得）。RustDesk でリモート操作する場合はダブルクリックで自分でインストールするか、インストール不要のポータブル版をそのまま実行してください
3. 右側の **Run workflow** ボタンをクリックすると、3 つの入力欄が表示されます

| パラメータ | 説明 |
|------|------|
| VNC パスワード | デスクトップ接続時に入力するパスワード。英数字のみ 8 文字以内（例：`abc12345`）。**必ずメモしてください** |
| 実行時間 | 今回のクラウドデスクトップを維持する分数。デフォルト 300（5 時間）、最大 350 |
| 解像度 | 初期デスクトップ解像度。デフォルト 1920x1080。ブラウザでページを開くとウィンドウサイズに合わせて自動で再調整されます |

4. 緑の **Run workflow** をクリックして確定すれば、クラウドデスクトップが起動します

### ステップ 3：アクセス URL を取得

1. Actions ページで、さっき開始した実行を開きます（一番上のもの。黄色い丸は実行中を表します）
2. 仮想マシンがソフトをインストールし、トンネルを構築するまで 3〜5 分ほど待ちます
3. **启动服务并建立隧道** というステップをクリックしてログを展開し、下にスクロールして次のようなアドレスを探します

```
https://xxx-xxx-xxx.trycloudflare.com/vnc.html
```

4. このアドレスをコピーしてブラウザで開きます（スマホの標準ブラウザで OK）

### ステップ 4：デスクトップに接続

1. 開いた noVNC ページで **Connect** をクリック
2. ステップ 2 で設定した VNC パスワードを入力
3. Windows デスクトップが表示されました 🎉
4. ページを開いてから約 10 秒で、デスクトップ解像度がブラウザのウィンドウに自動でフィットします。ウィンドウサイズを変えると自動で再調整されます（グラフィックカードが対応している解像度から選択）

> ⌨️ 入力方式の切り替えは **Win + Space**。搜狗ピンインと英語キーボードを切り替えられます。

### ステップ 5：使い終わったら終了

- Actions ページに戻り、その実行を開いて右上の **Cancel run** をクリック。仮想マシンが削除され、トンネルが無効になります
- 設定した実行時間を超えると自動で終了するので、ずっと動き続ける心配はありません

## ⚠️ 注意事項

- **実行ごとに URL が変わります**：前回の実行が終わると古い URL は無効になります。必ず最新の実行ログのアドレスを使ってください
- **データは保存されません**：仮想マシンが削除されると、デスクトップ上のファイル・ダウンロード・ログイン状態はすべて消去されます。大事なファイルは早めに取り出してください
- **パスワードのルール**：英数字のみ、8 文字以内。長すぎたり特殊文字が入ると接続できないことがあります（`Authentication failed` と表示）
- **Re-run は押さないで**：新しいデスクトップを開くときは **Run workflow** を押してください。Re-run は古いコードで実行されます
- **遅い・カクつく**：トンネルは Cloudflare 経由なので、中国本土からの速度はネットワーク次第です。実用レベルではあります
- **ページが開けない**：まずその実行がまだ進行中か確認してください（黄色い丸）。Cancel 済み・終了済みならアドレスは無効です

## ❓ よくある質問

| 症状 | 原因・対処 |
|------|-----------|
| `loopback connections are not enabled` | 旧バージョンのバグ。最新コードで Run workflow から再実行してください |
| `Server is not configured properly` | 旧バージョンのバグ。最新コードで Run workflow から再実行してください |
| `Authentication failed` | VNC パスワードの入力ミス、またはパスワードが 8 文字超・特殊文字入り |
| ページに 502 / 1033 が表示 | トンネルがまだ構築されていないか切断されています。数分待つか再実行してください |
| 解像度が自動で変わらない | 約 10 秒待ってください。ブラウザのウィンドウが実際に変化したか確認してください。一部の非標準解像度はグラフィックカードが未対応のため、最も近いものが自動選択されます |

## 🛠️ 自分でカスタマイズしたい？

ワークフローファイルは `.github/workflows/` の下にあります（`windows-vnc.yml` 標準版、`windows-vnc-rustdesk.yml` RustDesk 版）。GitHub の Web 上で直接編集でき、コミットすればすぐ反映されます。
