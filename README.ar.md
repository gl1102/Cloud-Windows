# ☁️ Cloud-Windows — سطح مكتب ويندوز سحابي مجاني

حوّل جهاز ويندوز الافتراضي المجاني في GitHub Actions إلى سطح مكتب سحابي يمكنك الوصول إليه من متصفحك. افتح صفحة ويب ويصبح لديك جهاز ويندوز — أغلقه عند الانتهاء. مجاني تمامًا.

## ✨ الميزات

- 🖥️ سطح مكتب ويندوز كامل، داخل متصفحك مباشرة (عميل noVNC الويبي)
- 📐 **الدقة التلقائية**: بعد فتح الصفحة، تتطابق دقة سطح المكتب تلقائيًا مع حجم نافذة المتصفح — الهواتف والحواسيب يحصل كل منها على المقاس المناسب، وتتبع التغيير أيضًا عند تغيير حجم النافذة
- 🌐 الوصول عبر Cloudflare Tunnel — لا حاجة لعنوان IP عام ولا لاختراق NAT
- ⌨️ طريقة إدخال Sogou Pinyin الصينية مدمجة، الإدخال بالصينية يعمل فورًا (اضغط `Win + Space` للتبديل بين الصينية والإنجليزية)
- 🖱️ الاتصال من الهاتف أو اللوحي أو الحاسوب
- ⏱️ كل تشغيل يدوم حتى ~6 ساعات، ويمكنك الإلغاء في أي وقت
- 📦 **نسخة RustDesk**: هناك أيضًا سير عمل RustDesk يقوم تلقائيًا بتنزيل أحدث RustDesk إلى القرص D وتثبيته بصمت في `D:\RustDesk`

## 🚀 الاستخدام (يعمل مباشرة بعد النسخ)

### الخطوة 1: انسخ (Fork) هذا المشروع

انقر زر **Fork** في الزاوية العلوية اليمنى من هذه الصفحة لنسخ المشروع إلى حساب GitHub الخاص بك. بعد النسخ ستنتقل إلى مستودع `your-username/Cloud-Windows`.

> 💡 لماذا النسخ؟ لا يمكن لـ GitHub Actions أن يعمل إلا في المستودعات التابعة لحسابك — النسخ يمنحك صلاحية التشغيل.

### الخطوة 2: شغّل سطح المكتب السحابي

1. انتقل إلى صفحة المستودع المنسوخ وانقر علامة التبويب **Actions** في الأعلى
2. اختر سير عمل من اليسار (اختر واحدًا):
   - **Windows Cloud Desktop**: سطح المكتب السحابي القياسي
   - **Windows Cloud Desktop + RustDesk**: النسخة القياسية بالإضافة إلى التنزيل التلقائي لأحدث RustDesk إلى القرص D مع التثبيت الصامت في `D:\RustDesk` (الإصدار غير مثبّت — يجلب دائمًا أحدث إصدار رسمي)
3. انقر زر **Run workflow** على اليمين — تظهر نافذة فيها ثلاثة حقول إدخال:

| المعامل | الوصف |
|------|------|
| كلمة مرور VNC | كلمة المرور التي ستدخلها عند الاتصال بسطح المكتب — حروف وأرقام فقط، حتى 8 أحرف (مثل `abc12345`). **سجّلها** |
| مدة التشغيل | عدد الدقائق التي يبقى فيها سطح المكتب السحابي حيًّا. الافتراضي 300 (5 ساعات)، والحد الأقصى 350 |
| الدقة | دقة سطح المكتب الأولية، الافتراضي 1920x1080؛ بمجرد فتح الصفحة في المتصفح تتعدل تلقائيًا وفق حجم نافذتك |

4. انقر زر **Run workflow** الأخضر للتأكيد — يبدأ إقلاع سطح المكتب السحابي

### الخطوة 3: احصل على رابط الوصول

1. في صفحة Actions، ادخل إلى التشغيل الذي بدأته للتو (الأعلى — النقطة الصفراء تعني أنه يعمل)
2. انتظر حوالي 3–5 دقائق حتى يثبت الجهاز الافتراضي البرامج ويعدّ النفق
3. انقر خطوة **启动服务并建立隧道**، ووسّع السجلات، ومرر للأسفل للعثور على رابط مثل:

```
https://xxx-xxx-xxx.trycloudflare.com/vnc.html
```

4. انسخ الرابط وافتحه في متصفحك (متصفح هاتفك المدمج يعمل جيدًا)

### الخطوة 4: الاتصال بسطح المكتب

1. في صفحة noVNC التي تفتح، انقر **Connect**
2. أدخل كلمة مرور VNC التي عيّنتها في الخطوة 2
3. أنت داخل — استمتع بسطح مكتب ويندوز 🎉
4. تتكيف دقة سطح المكتب تلقائيًا مع نافذة المتصفح خلال ~10 ثوانٍ من فتح الصفحة؛ تغيير حجم النافذة يؤدي إلى إعادة تكييف تلقائية (يُختار من الدقات التي تدعمها بطاقة الرسوميات لديك)

> ⌨️ اضغط **Win + Space** للتبديل بين طريقة إدخال Sogou Pinyin ولوحة المفاتيح الإنجليزية.

### الخطوة 5: أغلقه عند الانتهاء

- ارجع إلى صفحة Actions، وافتح التشغيل، وانقر **Cancel run** في الأعلى يمينًا — يُدمَّر الجهاز الافتراضي ويموت النفق
- ينتهي تلقائيًا أيضًا عند انقضاء المدة المحددة، فلا تقلق من استمراره للأبد

## ⚠️ ملاحظات

- **الرابط يتغير كل تشغيل**: الرابط القديم يتوقف عن العمل فور انتهاء التشغيل السابق، فاستخدم دائمًا رابط أحدث تشغيل من السجلات
- **لا يُحفظ شيء**: بمجرد تدمير الجهاز الافتراضي، تُمسح الملفات والتنزيلات وحالات تسجيل الدخول على سطح المكتب كلها — انقل الملفات المهمة في الوقت المناسب
- **قواعد كلمة المرور**: حروف وأرقام فقط، حتى 8 أحرف — كلمات المرور الأطول أو التي تحوي رموزًا خاصة قد تفشل في الاتصال (مع `Authentication failed`)
- **لا تنقر Re-run**: لبدء سطح مكتب جديد، انقر **Run workflow** — فـ Re-run يعيد تشغيل الشيفرة القديمة
- **اتصال بطيء/متقطع**: النفق يمر عبر Cloudflare؛ السرعات من البر الرئيسي الصيني تعتمد على شبكتك، لكنه قابل للاستخدام
- **الصفحة لا تفتح**: تحقق أولًا من أن التشغيل ما زال جاريًا (النقطة الصفراء) — إذا أُلغي أو انتهى فالرابط ميت

## ❓ الأسئلة الشائعة

| العرَض | السبب / الحل |
|------|-----------|
| `loopback connections are not enabled` | خطأ في نسخة قديمة — ابدأ تشغيلًا جديدًا بأحدث شيفرة عبر Run workflow |
| `Server is not configured properly` | خطأ في نسخة قديمة — ابدأ تشغيلًا جديدًا بأحدث شيفرة عبر Run workflow |
| `Authentication failed` | كلمة مرور VNC خاطئة، أو تتجاوز 8 أحرف / تحوي رموزًا خاصة |
| 502 / 1033 في الصفحة | النفق لم يرتفع بعد أو انقطع — انتظر بضع دقائق أو أعد التشغيل |
| الدقة لم تتغير تلقائيًا | انتظر ~10 ثوانٍ؛ تأكد من أن حجم نافذة المتصفح تغيّر فعلًا؛ بعض الدقات غير القياسية لا تدعمها بطاقة الرسوميات فيُختار أقرب دقة بدلًا منها |

## 🛠️ تريد تعديله بنفسك؟

ملفات سير العمل موجودة تحت `.github/workflows/` (`windows-vnc.yml` للنسخة القياسية، و`windows-vnc-rustdesk.yml` لنسخة RustDesk) — يمكنك تعديلها مباشرة على موقع GitHub؛ تدخل التغييرات حيز التنفيذ بعد الإيداع (commit).
