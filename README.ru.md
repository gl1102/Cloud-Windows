# ☁️ Cloud-Windows — бесплатный облачный Windows-десктоп

Бесплатная виртуальная машина Windows в GitHub Actions превращается в облачный рабочий стол, доступный прямо из браузера. Открыл страницу — и вот тебе Windows-компьютер, закончил — закрыл. Полностью бесплатно.

## ✨ Возможности

- 🖥️ Полноценный рабочий стол Windows прямо в браузере (веб-клиент noVNC)
- 📐 **Авторазрешение**: после открытия страницы разрешение рабочего стола автоматически подгоняется под размер окна браузера — и на телефоне, и на ПК; при изменении размера окна тоже подстраивается
- 🌐 Доступ через туннель Cloudflare — не нужен белый IP, не нужен проброс портов
- ⌨️ Встроенный Sogou Pinyin (搜狗输入法) — ввод на китайском работает из коробки (переключение китайский/английский — `Win + Space`)
- 🖱️ Подключайтесь с телефона, планшета или компьютера
- ⏱️ Один запуск длится до ~6 часов, можно остановить в любой момент
- 📦 **Версия с RustDesk**: есть также workflow с RustDesk — он автоматически скачивает свежий RustDesk на диск D и тихо устанавливает в `D:\RustDesk`

## 🚀 Использование (работает сразу после форка)

### Шаг 1. Сделайте форк проекта

Нажмите кнопку **Fork** в правом верхнем углу этой страницы, чтобы скопировать проект в свой аккаунт GitHub. После форка вы окажетесь в репозитории `ваше-имя-пользователя/Cloud-Windows`.

> 💡 Зачем нужен форк? GitHub Actions могут запускаться только в репозиториях вашего собственного аккаунта — форк даёт вам право нажать «запустить».

### Шаг 2. Запустите облачный десктоп

1. Откройте страницу вашего форка и перейдите на вкладку **Actions** сверху
2. Слева выберите workflow (один из двух):
   - **Windows Cloud Desktop**: стандартный облачный десктоп
   - **Windows Cloud Desktop + RustDesk**: стандартный, плюс автоматическая загрузка свежего RustDesk на диск D и тихая установка в `D:\RustDesk` (версия не захардкожена — всегда берётся последний официальный релиз)
3. Справа нажмите кнопку **Run workflow** — появится окно с тремя полями:

| Параметр | Описание |
|------|------|
| VNC-пароль | Пароль для подключения к рабочему столу — только латиница и цифры, не более 8 символов (например `abc12345`). **Запишите его** |
| Длительность | Сколько минут будет жить облачный десктоп. По умолчанию 300 (5 часов), максимум 350 |
| Разрешение | Стартовое разрешение рабочего стола, по умолчанию 1920x1080; после открытия страницы в браузере оно автоматически подстроится под окно |

4. Нажмите зелёную кнопку **Run workflow** — облачный десктоп начнёт запускаться

### Шаг 3. Получите адрес доступа

1. На странице Actions откройте только что запущенный запуск (самый верхний; жёлтая точка — идёт выполнение)
2. Подождите примерно 3–5 минут, пока виртуальная машина установит ПО и построит туннель
3. Нажмите на шаг **启动服务并建立隧道**, разверните журнал и прокрутите вниз до адреса вида:

```
https://xxx-xxx-xxx.trycloudflare.com/vnc.html
```

4. Скопируйте адрес и откройте его в браузере (подойдёт и встроенный браузер телефона)

### Шаг 4. Подключитесь к рабочему столу

1. На открывшейся странице noVNC нажмите **Connect**
2. Введите VNC-пароль, заданный на шаге 2
3. Вот и рабочий стол Windows — пользуйтесь 🎉
4. Разрешение рабочего стола автоматически подгонится под окно браузера примерно через 10 секунд после открытия страницы; при изменении размера окна произойдёт повторная подгонка (выбор из разрешений, поддерживаемых видеокартой)

> ⌨️ Переключение раскладки — **Win + Space**: Sogou Pinyin ↔ английская клавиатура.

### Шаг 5. Закончили — выключите

- Вернитесь на страницу Actions, откройте запуск и нажмите **Cancel run** в правом верхнем углу — виртуальная машина будет удалена, туннель перестанет работать
- По истечении заданной длительности всё завершится автоматически, беспокоиться не о чем

## ⚠️ Важно знать

- **Адрес меняется при каждом запуске**: старый адрес перестаёт работать, как только завершится предыдущий запуск, — всегда берите адрес из журнала последнего запуска
- **Данные не сохраняются**: после удаления виртуальной машины файлы, загрузки и входы на рабочем столе стираются полностью — важные файлы выгружайте заранее
- **Правила пароля**: только латиница и цифры, не более 8 символов — более длинный или со спецсимволами может не подключиться (ошибка `Authentication failed`)
- **Не нажимайте Re-run**: для нового десктопа жмите **Run workflow**, Re-run запускает старый код
- **Медленно/тормозит**: туннель идёт через Cloudflare, скорость из материкового Китая зависит от сети — в целом терпимо
- **Страница не открывается**: сначала проверьте, что запуск ещё идёт (жёлтая точка) — если он отменён или завершён, адрес недействителен

## ❓ Частые вопросы

| Симптом | Причина / решение |
|------|-----------|
| `loopback connections are not enabled` | Баг старой версии — запустите заново через Run workflow на свежем коде |
| `Server is not configured properly` | Баг старой версии — запустите заново через Run workflow на свежем коде |
| `Authentication failed` | Неверный VNC-пароль, либо пароль длиннее 8 символов / содержит спецсимволы |
| 502 / 1033 на странице | Туннель ещё не поднялся или оборвался — подождите несколько минут или запустите заново |
| Разрешение не изменилось само | Подождите ~10 секунд; убедитесь, что окно браузера реально изменило размер; часть нестандартных разрешений видеокарта не поддерживает — будет выбрано ближайшее |

## 🛠️ Хотите изменить под себя?

Файлы workflow — в `.github/workflows/` (`windows-vnc.yml` — стандартная версия, `windows-vnc-rustdesk.yml` — версия с RustDesk), их можно править прямо на сайте GitHub, изменения вступят в силу после коммита.
