# ☁️ Cloud-Windows — دسکتاپ ابری ویندوز رایگان

یک ماشین مجازی ویندوز رایگان GitHub Actions را به یک دسکتاپ ابری تبدیل کنید که می‌توانید از طریق مرورگر به آن دسترسی داشته باشید. یک صفحه وب باز کنید و یک کامپیوتر ویندوزی در اختیار دارید — وقتی کارتان تمام شد آن را خاموش کنید. کاملاً رایگان.

## ✨ ویژگی‌ها

- 🖥️ یک دسکتاپ کامل ویندوز، دقیقاً داخل مرورگر شما (کلاینت وب noVNC)
- 📐 **وضوح خودکار**: پس از باز کردن صفحه، وضوح دسکتاپ به‌صورت خودکار با اندازه پنجره مرورگر شما تنظیم می‌شود — گوشی و کامپیوتر هر کدام اندازه مناسب خود را می‌گیرند؛ با تغییر اندازه پنجره نیز تطبیق داده می‌شود
- 🌐 دسترسی از طریق تونل Cloudflare — بدون نیاز به IP عمومی یا پیمایش NAT
- ⌨️ روش ورودی چینی Sogou Pinyin داخلی، ورودی چینی از همان ابتدا کار می‌کند (برای جابه‌جایی بین چینی و انگلیسی `Win + Space` را فشار دهید)
- 🖱️ از گوشی، تبلت یا کامپیوتر وصل شوید
- ⏱️ هر اجرا تا ~6 ساعت طول می‌کشد و هر زمان می‌توانید آن را لغو کنید
- 📦 **نسخه RustDesk**: یک گردش‌کار RustDesk هم هست که به‌صورت خودکار فایل نصب آخرین RustDesk را روی دسکتاپ دانلود می‌کند

## 🚀 استفاده (بلافاصله بعد از فورک کار می‌کند)

### مرحله ۱: این پروژه را فورک (Fork) کنید

روی دکمه **Fork** در گوشه بالای راست این صفحه کلیک کنید تا پروژه در حساب GitHub خودتان کپی شود. پس از فورک وارد مخزن `your-username/Cloud-Windows` می‌شوید.

> 💡 چرا فورک؟ GitHub Actions فقط در مخازن متعلق به حساب خودتان اجرا می‌شود — فورک کردن مجوز اجرا را به شما می‌دهد.

### مرحله ۲: دسکتاپ ابری را اجرا کنید

1. به صفحه مخزن فورک‌شده بروید و روی تب **Actions** در بالا کلیک کنید
2. از سمت چپ یک گردش‌کار انتخاب کنید (یکی را انتخاب کنید):
   - **Windows Cloud Desktop**: دسکتاپ ابری استاندارد
   - **Windows Cloud Desktop + RustDesk**: نسخه استاندارد به‌علاوه دانلود خودکار فایل نصب آخرین RustDesk روی دسکتاپ (نسخه هاردکد نشده — همیشه آخرین نسخه رسمی را می‌گیرد)؛ هر وقت به کنترل از راه دور نیاز داشتید، برای نصب دابل‌کلیک کنید
3. روی دکمه **Run workflow** در سمت راست کلیک کنید — پنجره‌ای با سه ورودی باز می‌شود:

| پارامتر | توضیح |
|------|------|
| رمز عبور VNC | رمزی که هنگام اتصال به دسکتاپ وارد می‌کنید — فقط حروف و اعداد، حداکثر ۸ کاراکتر (مثلاً `abc12345`). **یادداشتش کنید** |
| مدت اجرا | چند دقیقه این دسکتاپ ابری زنده می‌ماند. پیش‌فرض ۳۰۰ (۵ ساعت)، حداکثر ۳۵۰ |
| وضوح | وضوح اولیه دسکتاپ، پیش‌فرض 1920x1080؛ به‌محض باز کردن صفحه در مرورگر، خودکار با اندازه پنجره شما تنظیم می‌شود |

4. روی دکمه سبز **Run workflow** کلیک کنید تا تأیید شود — بوت دسکتاپ ابری شروع می‌شود

### مرحله ۳: لینک دسترسی را بگیرید

1. در صفحه Actions وارد اجرایی شوید که تازه شروع کردید (بالاترین مورد — نقطه زرد یعنی در حال اجراست)
2. حدود ۳ تا ۵ دقیقه صبر کنید تا ماشین مجازی نرم‌افزارها را نصب و تونل را راه‌اندازی کند
3. روی مرحله **启动服务并建立隧道** کلیک کنید، لاگ‌ها را باز کنید و به پایین اسکرول کنید تا لینکی مثل این را پیدا کنید:

```
https://xxx-xxx-xxx.trycloudflare.com/vnc.html
```

4. لینک را کپی کنید و در مرورگر باز کنید (مرورگر داخلی گوشی هم خوب کار می‌کند)

### مرحله ۴: به دسکتاپ وصل شوید

1. در صفحه noVNC که باز می‌شود روی **Connect** کلیک کنید
2. رمز عبور VNC‌ای را که در مرحله ۲ تعیین کردید وارد کنید
3. وارد شدید — از دسکتاپ ویندوز لذت ببرید 🎉
4. وضوح دسکتاپ ظرف حدود ۱۰ ثانیه پس از باز شدن صفحه، خودکار با پنجره مرورگر شما تطبیق داده می‌شود؛ تغییر اندازه پنجره باعث تطبیق مجدد خودکار می‌شود (از میان وضوح‌هایی که GPU شما پشتیبانی می‌کند انتخاب می‌شود)

> ⌨️ برای جابه‌جایی روش ورودی بین Sogou Pinyin و صفحه‌کلید انگلیسی، **Win + Space** را فشار دهید.

### مرحله ۵: وقتی تمام شدید خاموشش کنید

- به صفحه Actions برگردید، آن اجرا را باز کنید و روی **Cancel run** در بالای راست کلیک کنید — ماشین مجازی نابود و تونل قطع می‌شود
- با پایان یافتن مدت تعیین‌شده هم به‌صورت خودکار تمام می‌شود، پس نگران اجرا شدن همیشگی نباشید

## ⚠️ نکته‌ها

- **لینک هر بار عوض می‌شود**: به‌محض پایان اجرای قبلی، لینک قدیمی از کار می‌افتد؛ پس همیشه از لینک آخرین اجرا در لاگ‌ها استفاده کنید
- **هیچ‌چیز ذخیره نمی‌شود**: با نابودی ماشین مجازی، فایل‌ها، دانلودها و وضعیت‌های ورود در دسکتاپ همه پاک می‌شوند — فایل‌های مهم را به‌موقع خارج کنید
- **قوانین رمز عبور**: فقط حروف و اعداد، حداکثر ۸ کاراکتر — رمزهای طولانی‌تر یا دارای کاراکتر خاص ممکن است اتصال را با خطا مواجه کنند (`Authentication failed`)
- **روی Re-run کلیک نکنید**: برای شروع یک دسکتاپ جدید روی **Run workflow** کلیک کنید — Re-run کد قدیمی را اجرا می‌کند
- **اتصال کند/لگ‌دار**: تونل از طریق Cloudflare می‌گذرد؛ سرعت‌ها از داخل چین به شبکه شما بستگی دارد، اما قابل استفاده است
- **صفحه باز نمی‌شود**: اول بررسی کنید اجرا هنوز در جریان است (نقطه زرد) — اگر لغو یا تمام شده باشد، لینک مرده است

## ❓ سوالات متداول

| علامت | علت / راه‌حل |
|------|-----------|
| `loopback connections are not enabled` | باگ نسخه قدیمی — با Run workflow یک اجرای تازه با آخرین کد شروع کنید |
| `Server is not configured properly` | باگ نسخه قدیمی — با Run workflow یک اجرای تازه با آخرین کد شروع کنید |
| `Authentication failed` | رمز عبور VNC اشتباه است، یا بیش از ۸ کاراکتر است / کاراکتر خاص دارد |
| 502 / 1033 در صفحه | تونل هنوز بالا نیامده یا قطع شده — چند دقیقه صبر کنید یا دوباره اجرا کنید |
| وضوح به‌صورت خودکار تغییر نکرد | ~۱۰ ثانیه صبر کنید؛ مطمئن شوید اندازه پنجره مرورگر واقعاً تغییر کرده؛ بعضی وضوح‌های غیراستاندارد توسط GPU پشتیبانی نمی‌شوند و نزدیک‌ترین وضوح انتخاب می‌شود |

## 🛠️ می‌خواهید خودتان دست‌کاریش کنید؟

فایل‌های گردش‌کار زیر `.github/workflows/` هستند (`windows-vnc.yml` برای نسخه استاندارد، `windows-vnc-rustdesk.yml` برای نسخه RustDesk) — می‌توانید مستقیماً در وب‌سایت GitHub ویرایششان کنید؛ تغییرات پس از کامیت اعمال می‌شوند.
