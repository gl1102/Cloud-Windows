# ☁️ Cloud-Windows — Δωρεάν απομακρυσμένη επιφάνεια εργασίας Windows

Μετατρέψτε μια δωρεάν εικονική μηχανή Windows του GitHub Actions σε έναν cloud υπολογιστή που προσπελάζεται από το πρόγραμμα περιήγησής σας. Ανοίξτε μια ιστοσελίδα και έχετε έναν υπολογιστή Windows — κλείστε τον όταν τελειώσετε. Εντελώς δωρεάν.

## ✨ Χαρακτηριστικά

- 🖥️ Μια πλήρης επιφάνεια εργασίας Windows, μέσα στο πρόγραμμα περιήγησής σας (web client noVNC)
- 📐 **Αυτόματη ανάλυση**: αφού ανοίξετε τη σελίδα, η ανάλυση της επιφάνειας εργασίας προσαρμόζεται αυτόματα στο μέγεθος του παραθύρου του προγράμματος περιήγησής σας — τηλέφωνα και υπολογιστές παίρνουν το σωστό μέγεθος· ακολουθεί και όταν αλλάζετε το μέγεθος του παραθύρου
- 🌐 Πρόσβαση μέσω σήραγγας Cloudflare — δεν χρειάζεται δημόσια IP ούτε διάνοιξη NAT
- ⌨️ Ενσωματωμένο πληκτρολόγιο Sogou Pinyin, η εισαγωγή κινεζικών λειτουργεί αμέσως (πατήστε `Win + Space` για εναλλαγή μεταξύ κινεζικών και αγγλικών)
- 🖱️ Συνδεθείτε από το τηλέφωνο, το tablet ή τον υπολογιστή σας
- ⏱️ Κάθε εκτέλεση διαρκεί έως ~6 ώρες και μπορείτε να την ακυρώσετε ανά πάσα στιγμή
- 📦 **Έκδοση RustDesk**: υπάρχει επίσης ένα workflow RustDesk που κατεβάζει αυτόματα το τελευταίο πρόγραμμα εγκατάστασης του RustDesk στην επιφάνεια εργασίας

## 🚀 Χρήση (λειτουργεί αμέσως μετά το fork)

### Βήμα 1: Κάντε Fork αυτό το έργο

Πατήστε το κουμπί **Fork** πάνω δεξιά σε αυτή τη σελίδα για να αντιγράψετε το έργο στον δικό σας λογαριασμό GitHub. Μόλις γίνει το fork, θα βρεθείτε στο αποθετήριο `your-username/Cloud-Windows`.

> 💡 Γιατί fork; Το GitHub Actions μπορεί να εκτελείται μόνο σε αποθετήρια του δικού σας λογαριασμού — το fork σάς δίνει την άδεια να το εκτελέσετε.

### Βήμα 2: Εκκινήστε την cloud επιφάνεια εργασίας

1. Μεταβείτε στη σελίδα του fork σας και πατήστε την καρτέλα **Actions** στο επάνω μέρος
2. Επιλέξτε ένα workflow στα αριστερά (διαλέξτε ένα):
   - **Windows Cloud Desktop**: η τυπική cloud επιφάνεια εργασίας
   - **Windows Cloud Desktop + RustDesk**: η τυπική έκδοση συν αυτόματη λήψη του τελευταίου προγράμματος εγκατάστασης του RustDesk στην επιφάνεια εργασίας (η έκδοση δεν είναι προκαθορισμένη — κατεβάζει πάντα την τελευταία επίσημη έκδοση)· κάντε διπλό κλικ για εγκατάσταση όταν χρειάζεστε απομακρυσμένο έλεγχο
3. Πατήστε το κουμπί **Run workflow** στα δεξιά — εμφανίζεται ένα παράθυρο με τρία πεδία εισαγωγής:

| Παράμετρος | Περιγραφή |
|------|------|
| Κωδικός VNC | Ο κωδικός που θα πληκτρολογήσετε για να συνδεθείτε στην επιφάνεια εργασίας — μόνο γράμματα και αριθμοί, έως 8 χαρακτήρες (π.χ. `abc12345`). **Σημειώστε τον** |
| Διάρκεια εκτέλεσης | Πόσα λεπτά παραμένει ενεργή αυτή η συνεδρία cloud επιφάνειας εργασίας. Προεπιλογή 300 (5 ώρες), μέγιστο 350 |
| Ανάλυση | Η αρχική ανάλυση της επιφάνειας εργασίας, προεπιλογή 1920x1080· μόλις ανοίξετε τη σελίδα στο πρόγραμμα περιήγησής σας προσαρμόζεται αυτόματα στο μέγεθος του παραθύρου |

4. Πατήστε το πράσινο κουμπί **Run workflow** για επιβεβαίωση — η cloud επιφάνεια εργασίας ξεκινάει

### Βήμα 3: Λάβετε το URL πρόσβασης

1. Στη σελίδα Actions, μπείτε στην εκτέλεση που μόλις ξεκινήσατε (η πάνω-πάνω — η κίτρινη κουκκίδα σημαίνει ότι εκτελείται)
2. Περιμένετε περίπου 3–5 λεπτά μέχρι η VM να εγκαταστήσει το λογισμικό και να δημιουργήσει τη σήραγγα
3. Πατήστε το βήμα **启动服务并建立隧道**, αναπτύξτε τα αρχεία καταγραφής και κάντε κύλιση προς τα κάτω για να βρείτε ένα URL σαν αυτό:

```
https://xxx-xxx-xxx.trycloudflare.com/vnc.html
```

4. Αντιγράψτε το URL και ανοίξτε το στο πρόγραμμα περιήγησής σας (το ενσωματωμένο πρόγραμμα περιήγησης του τηλεφώνου σας λειτουργεί μια χαρά)

### Βήμα 4: Συνδεθείτε στην επιφάνεια εργασίας

1. Στη σελίδα noVNC που ανοίγει, πατήστε **Connect**
2. Πληκτρολογήστε τον κωδικό VNC που ορίσατε στο Βήμα 2
3. Μπήκατε — απολαύστε την επιφάνεια εργασίας των Windows 🎉
4. Η ανάλυση της επιφάνειας εργασίας θα προσαρμοστεί αυτόματα στο παράθυρο του προγράμματος περιήγησής σας περίπου 10 δευτερόλεπτα μετά το άνοιγμα της σελίδας· η αλλαγή μεγέθους του παραθύρου ενεργοποιεί αυτόματη επαναπροσαρμογή (επιλέγεται από τις αναλύσεις που υποστηρίζει η GPU σας)

> ⌨️ Πατήστε **Win + Space** για εναλλαγή της μεθόδου εισαγωγής μεταξύ Sogou Pinyin και αγγλικού πληκτρολογίου.

### Βήμα 5: Κλείστε την όταν τελειώσετε

- Επιστρέψτε στη σελίδα Actions, ανοίξτε την εκτέλεση και πατήστε **Cancel run** πάνω δεξιά — η VM καταστρέφεται και η σήραγγα κλείνει
- Τερματίζεται επίσης αυτόματα μόλις περάσει η καθορισμένη διάρκεια, οπότε μην ανησυχείτε

## ⚠️ Σημειώσεις

- **Το URL αλλάζει σε κάθε εκτέλεση**: το παλιό URL σταματά να λειτουργεί μόλις τελειώσει η προηγούμενη εκτέλεση, οπότε χρησιμοποιείτε πάντα το URL από τα αρχεία καταγραφής της τελευταίας εκτέλεσης
- **Δεν αποθηκεύεται τίποτα**: μόλις καταστραφεί η VM, τα αρχεία, οι λήψεις και οι καταστάσεις σύνδεσης στην επιφάνεια εργασίας διαγράφονται όλα — μετακινήστε έγκαιρα τα σημαντικά αρχεία
- **Κανόνες κωδικού**: μόνο γράμματα και αριθμοί, έως 8 χαρακτήρες — μεγαλύτεροι κωδικοί ή με ειδικούς χαρακτήρες ενδέχεται να αποτύχουν στη σύνδεση (με `Authentication failed`)
- **Μην πατάτε Re-run**: για νέα επιφάνεια εργασίας πατήστε **Run workflow** — το Re-run εκτελεί τον παλιό κώδικα
- **Αργή σύνδεση**: η σήραγγα περνάει από το Cloudflare· οι ταχύτητες από την ηπειρωτική Κίνα εξαρτώνται από το δίκτυό σας, αλλά είναι χρησιμοποιήσιμη
- **Η σελίδα δεν ανοίγει**: ελέγξτε πρώτα ότι η εκτέλεση είναι ακόμα σε εξέλιξη (κίτρινη κουκκίδα) — αν ακυρώθηκε ή τελείωσε, το URL είναι νεκρό

## ❓ FAQ

| Σύμπτωμα | Αιτία / Λύση |
|------|-----------|
| `loopback connections are not enabled` | Σφάλμα παλιάς έκδοσης — ξεκινήστε μια νέα εκτέλεση με τον τελευταίο κώδικα μέσω Run workflow |
| `Server is not configured properly` | Σφάλμα παλιάς έκδοσης — ξεκινήστε μια νέα εκτέλεση με τον τελευταίο κώδικα μέσω Run workflow |
| `Authentication failed` | Λάθος κωδικός VNC, ή κωδικός άνω των 8 χαρακτήρων / με ειδικούς χαρακτήρες |
| 502 / 1033 στη σελίδα | Η σήραγγα δεν έχει στηθεί ακόμα ή έπεσε — περιμένετε λίγα λεπτά ή ξανατρέξτε |
| Η ανάλυση δεν άλλαξε αυτόματα | Περιμένετε ~10 δευτερόλεπτα· βεβαιωθείτε ότι το μέγεθος του παραθύρου του προγράμματος περιήγησης άλλαξε πραγματικά· ορισμένες μη τυπικές αναλύσεις δεν υποστηρίζονται από την GPU και επιλέγεται η πλησιέστερη |

## 🛠️ Θέλετε να το προσαρμόσετε μόνοι σας;

Τα αρχεία workflow βρίσκονται στο `.github/workflows/` (`windows-vnc.yml` για την τυπική έκδοση, `windows-vnc-rustdesk.yml` για την έκδοση RustDesk) — μπορείτε να τα επεξεργαστείτε απευθείας στον ιστότοπο του GitHub· οι αλλαγές ισχύουν μετά το commit.
