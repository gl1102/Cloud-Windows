# ☁️ Cloud-Windows — സൗജന്യ ക്ലൗഡ് Windows ഡെസ്ക്ടോപ്പ്

GitHub Actions-ന്റെ സൗജന്യ Windows വെർച്വൽ മെഷീനെ ബ്രൗസറിൽ നിന്ന് ഉപയോഗിക്കാവുന്ന ക്ലൗഡ് ഡെസ്ക്ടോപ്പാക്കി മാറ്റൂ. ഒരു വെബ് പേജ് തുറന്നാൽ നിങ്ങൾക്ക് ഒരു Windows PC ലഭിക്കും — ജോലി കഴിഞ്ഞാൽ അത് ഓഫ് ചെയ്യൂ. പൂർണ്ണമായും സൗജന്യം.

## ✨ സവിശേഷതകൾ

- 🖥️ നിങ്ങളുടെ ബ്രൗസറിൽ തന്നെ ഒരു പൂർണ്ണ Windows ഡെസ്ക്ടോപ്പ് (noVNC വെബ് ക്ലയന്റ്)
- 📐 **യാന്ത്രിക റെസല്യൂഷൻ**: പേജ് തുറന്ന ശേഷം, ഡെസ്ക്ടോപ്പ് റെസല്യൂഷൻ നിങ്ങളുടെ ബ്രൗസർ വിൻഡോയുടെ വലുപ്പത്തിന് അനുസരിച്ച് യാന്ത്രികമായി ക്രമീകരിക്കും — ഫോണിനും PC-യ്ക്കും ഓരോന്നിനും അനുയോജ്യമായ വലുപ്പം ലഭിക്കും; വിൻഡോ വലുപ്പം മാറ്റുമ്പോഴും അത് പിന്തുടരും
- 🌐 Cloudflare ടണൽ വഴി ആക്സസ് — പബ്ലിക് IP ആവശ്യമില്ല, NAT ട്രാവേഴ്സൽ ആവശ്യമില്ല
- ⌨️ അന്തർനിർമ്മിത Sogou Pinyin ഇൻപുട്ട് രീതി, ചൈനീസ് ഇൻപുട്ട് ഉടൻ പ്രവർത്തിക്കും (`Win + Space` അമർത്തി ചൈനീസിനും ഇംഗ്ലീഷിനും ഇടയിൽ മാറൂ)
- 🖱️ ഫോണിൽ നിന്നോ ടാബ്‌ലെറ്റിൽ നിന്നോ കമ്പ്യൂട്ടറിൽ നിന്നോ കണക്ട് ചെയ്യൂ
- ⏱️ ഓരോ റണ്ണും ~6 മണിക്കൂർ വരെ നീണ്ടുനിൽക്കും, എപ്പോൾ വേണമെങ്കിലും റദ്ദാക്കാം
- 📦 **RustDesk പതിപ്പ്**: ഏറ്റവും പുതിയ RustDesk ഇൻസ്റ്റലർ ഡെസ്ക്ടോപ്പിലേക്ക് യാന്ത്രികമായി ഡൗൺലോഡ് ചെയ്യുന്ന ഒരു RustDesk വർക്ക്ഫ്ലോയും ഉണ്ട്

## 🚀 ഉപയോഗം (ഫോർക്ക് ചെയ്താൽ ഉടൻ പ്രവർത്തിക്കും)

### ഘട്ടം 1: ഈ പ്രോജക്റ്റ് Fork ചെയ്യൂ

ഈ പേജിന്റെ മുകളിൽ വലതുവശത്തുള്ള **Fork** ബട്ടണിൽ ക്ലിക്ക് ചെയ്ത് പ്രോജക്റ്റ് നിങ്ങളുടെ GitHub അക്കൗണ്ടിലേക്ക് പകർത്തൂ. ഫോർക്ക് ചെയ്തുകഴിഞ്ഞാൽ നിങ്ങൾ `your-username/Cloud-Windows` റിപ്പോസിറ്ററിയിലെത്തും.

> 💡 എന്തിനാണ് ഫോർക്ക്? GitHub Actions നിങ്ങളുടെ സ്വന്തം അക്കൗണ്ടിലെ റിപ്പോസിറ്ററികളിൽ മാത്രമേ പ്രവർത്തിക്കൂ — ഫോർക്ക് അത് പ്രവർത്തിപ്പിക്കാനുള്ള അനുമതി നൽകുന്നു.

### ഘട്ടം 2: ക്ലൗഡ് ഡെസ്ക്ടോപ്പ് ആരംഭിക്കൂ

1. നിങ്ങളുടെ ഫോർക്ക് ചെയ്ത റിപ്പോസിറ്ററി പേജിൽ പോയി മുകളിലുള്ള **Actions** ടാബിൽ ക്ലിക്ക് ചെയ്യൂ
2. ഇടതുവശത്ത് ഒരു വർക്ക്ഫ്ലോ തിരഞ്ഞെടുക്കൂ (ഒന്ന് തിരഞ്ഞെടുക്കുക):
   - **Windows Cloud Desktop**: സ്റ്റാൻഡേർഡ് ക്ലൗഡ് ഡെസ്ക്ടോപ്പ്
   - **Windows Cloud Desktop + RustDesk**: സ്റ്റാൻഡേർഡ് പതിപ്പിനൊപ്പം ഏറ്റവും പുതിയ RustDesk ഇൻസ്റ്റലർ ഡെസ്ക്ടോപ്പിലേക്ക് യാന്ത്രിക ഡൗൺലോഡ് (വേർഷൻ ഹാർഡ്കോഡ് ചെയ്തിട്ടില്ല — എപ്പോഴും ഏറ്റവും പുതിയ ഔദ്യോഗിക റിലീസ് എടുക്കും); റിമോട്ട് കൺട്രോൾ വേണമെങ്കിൽ ഡബിൾ ക്ലിക്ക് ചെയ്ത് ഇൻസ്റ്റാൾ ചെയ്യാം
3. വലതുവശത്തുള്ള **Run workflow** ബട്ടണിൽ ക്ലിക്ക് ചെയ്യൂ — മൂന്ന് ഇൻപുട്ട് ഫീൽഡുകളുള്ള ഒരു ഡയലോഗ് തുറക്കും:

| പാരാമീറ്റർ | വിവരണം |
|------|------|
| VNC പാസ്‌വേഡ് | ഡെസ്ക്ടോപ്പിലേക്ക് കണക്ട് ചെയ്യുമ്പോൾ നിങ്ങൾ നൽകുന്ന പാസ്‌വേഡ് — അക്ഷരങ്ങളും അക്കങ്ങളും മാത്രം, പരമാവധി 8 അക്ഷരങ്ങൾ (ഉദാ. `abc12345`). **എഴുതിവെക്കൂ** |
| റൺ ദൈർഘ്യം | ഈ ക്ലൗഡ് ഡെസ്ക്ടോപ്പ് സെഷൻ എത്ര മിനിറ്റ് നിലനിൽക്കും. സ്ഥിരസ്ഥിതി 300 (5 മണിക്കൂർ), പരമാവധി 350 |
| റെസല്യൂഷൻ | ഡെസ്ക്ടോപ്പിന്റെ പ്രാരംഭ റെസല്യൂഷൻ, സ്ഥിരസ്ഥിതി 1920x1080; ബ്രൗസറിൽ പേജ് തുറന്നുകഴിഞ്ഞാൽ അത് വിൻഡോ വലുപ്പത്തിന് അനുസരിച്ച് യാന്ത്രികമായി ക്രമീകരിക്കും |

4. സ്ഥിരീകരിക്കാൻ പച്ച **Run workflow** ബട്ടണിൽ ക്ലിക്ക് ചെയ്യൂ — ക്ലൗഡ് ഡെസ്ക്ടോപ്പ് ബൂട്ട് ചെയ്യാൻ തുടങ്ങും

### ഘട്ടം 3: ആക്സസ് URL നേടൂ

1. Actions പേജിൽ, നിങ്ങൾ ആരംഭിച്ച റണ്ണിൽ ക്ലിക്ക് ചെയ്യൂ (ഏറ്റവും മുകളിലത്തേത് — മഞ്ഞ ഡോട്ട് എന്നാൽ അത് പ്രവർത്തിക്കുന്നുവെന്നാണ്)
2. VM സോഫ്റ്റ്‌വെയർ ഇൻസ്റ്റാൾ ചെയ്ത് ടണൽ സജ്ജീകരിക്കാൻ ഏകദേശം 3–5 മിനിറ്റ് കാത്തിരിക്കൂ
3. **启动服务并建立隧道** ഘട്ടത്തിൽ ക്ലിക്ക് ചെയ്ത് ലോഗുകൾ വിപുലീകരിച്ച് താഴേക്ക് സ്ക്രോൾ ചെയ്ത് ഇതുപോലെയൊരു URL കണ്ടെത്തൂ:

```
https://xxx-xxx-xxx.trycloudflare.com/vnc.html
```

4. URL പകർത്തി നിങ്ങളുടെ ബ്രൗസറിൽ തുറക്കൂ (ഫോണിന്റെ അന്തർനിർമ്മിത ബ്രൗസർ നന്നായി പ്രവർത്തിക്കും)

### ഘട്ടം 4: ഡെസ്ക്ടോപ്പിലേക്ക് കണക്ട് ചെയ്യൂ

1. തുറക്കുന്ന noVNC പേജിൽ **Connect** ക്ലിക്ക് ചെയ്യൂ
2. ഘട്ടം 2-ൽ സജ്ജീകരിച്ച VNC പാസ്‌വേഡ് നൽകൂ
3. നിങ്ങൾ അകത്തായി — Windows ഡെസ്ക്ടോപ്പ് ആസ്വദിക്കൂ 🎉
4. പേജ് തുറന്ന് ഏകദേശം 10 സെക്കൻഡിനുള്ളിൽ ഡെസ്ക്ടോപ്പ് റെസല്യൂഷൻ നിങ്ങളുടെ ബ്രൗസർ വിൻഡോയ്ക്ക് അനുസരിച്ച് യാന്ത്രികമായി ക്രമീകരിക്കും; വിൻഡോ വലുപ്പം മാറ്റുന്നത് യാന്ത്രിക പുനഃക്രമീകരണത്തിന് പ്രേരണയാകും (നിങ്ങളുടെ GPU പിന്തുണയ്ക്കുന്ന റെസല്യൂഷനുകളിൽ നിന്ന് തിരഞ്ഞെടുക്കും)

> ⌨️ Sogou Pinyin-ഉം ഇംഗ്ലീഷ് കീബോർഡും തമ്മിൽ ഇൻപുട്ട് രീതി മാറ്റാൻ **Win + Space** അമർത്തൂ.

### ഘട്ടം 5: ജോലി കഴിഞ്ഞാൽ അത് ഓഫ് ചെയ്യൂ

- Actions പേജിലേക്ക് മടങ്ങി, റൺ തുറന്ന് മുകളിൽ വലതുവശത്തുള്ള **Cancel run** ക്ലിക്ക് ചെയ്യൂ — VM നശിപ്പിക്കപ്പെടും, ടണൽ പ്രവർത്തനരഹിതമാകും
- നിശ്ചയിച്ച ദൈർഘ്യം കഴിഞ്ഞാൽ അത് യാന്ത്രികമായും അവസാനിക്കും, അതിനാൽ ആശങ്ക വേണ്ട

## ⚠️ കുറിപ്പുകൾ

- **URL ഓരോ റണ്ണിലും മാറും**: മുൻ റൺ അവസാനിച്ചാൽ ഉടൻ പഴയ URL പ്രവർത്തനരഹിതമാകും, അതിനാൽ എപ്പോഴും ഏറ്റവും പുതിയ റണ്ണിന്റെ ലോഗുകളിൽ നിന്നുള്ള URL ഉപയോഗിക്കൂ
- **ഒന്നും സംരക്ഷിക്കപ്പെടുന്നില്ല**: VM നശിപ്പിക്കപ്പെട്ടാൽ, ഡെസ്ക്ടോപ്പിലെ ഫയലുകളും ഡൗൺലോഡുകളും ലോഗിൻ അവസ്ഥകളും എല്ലാം മാഞ്ഞുപോകും — പ്രധാനപ്പെട്ട ഫയലുകൾ സമയത്തിന് പുറത്തേക്ക് മാറ്റൂ
- **പാസ്‌വേഡ് നിയമങ്ങൾ**: അക്ഷരങ്ങളും അക്കങ്ങളും മാത്രം, പരമാവധി 8 അക്ഷരങ്ങൾ — നീളമുള്ളതോ പ്രത്യേക അക്ഷരങ്ങളുള്ളതോ ആയ പാസ്‌വേഡുകളുമായി കണക്ഷൻ പരാജയപ്പെടാം (`Authentication failed`)
- **Re-run ക്ലിക്ക് ചെയ്യരുത്**: പുതിയ ഡെസ്ക്ടോപ്പ് ആരംഭിക്കാൻ **Run workflow** ക്ലിക്ക് ചെയ്യൂ — Re-run പഴയ കോഡ് വീണ്ടും പ്രവർത്തിപ്പിക്കും
- **മന്ദഗതിയിലുള്ള/ലാഗ് ആയ കണക്ഷൻ**: ടണൽ Cloudflare വഴിയാണ്; ചൈനയിൽ നിന്നുള്ള വേഗത നിങ്ങളുടെ നെറ്റ്‌വർക്കിനെ ആശ്രയിച്ചിരിക്കും, പക്ഷേ ഉപയോഗയോഗ്യമാണ്
- **പേജ് തുറക്കുന്നില്ല**: ആദ്യം റൺ ഇപ്പോഴും പുരോഗമിക്കുന്നുണ്ടോ എന്ന് പരിശോധിക്കൂ (മഞ്ഞ ഡോട്ട്) — അത് റദ്ദാക്കുകയോ പൂർത്തിയാക്കുകയോ ചെയ്തിട്ടുണ്ടെങ്കിൽ, URL പ്രവർത്തനരഹിതമാണ്
